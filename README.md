# Lunettes Soleil

Projet de page vitrine pour une marque de lunettes de soleil.

## Description

Cette application consiste en une page HTML/CSS/JavaScript simple présentant un produit ou une collection de lunettes de soleil avec une mise en page moderne et élégante.

## Fichiers du projet

- `index.html` : structure de la page
- `style.css` : styles et mise en page
- `script.js` : interactions JavaScript

## Prérequis

Aucun prérequis particulier n'est nécessaire pour visualiser le projet.

## Utilisation

1. Ouvrez le fichier `index.html` dans votre navigateur.
2. Ou bien lancez un petit serveur local si vous préférez :

```bash
python -m http.server 8000
```

Puis ouvrez : http://localhost:8000

## Objectif

Mettre en avant un design visuel attrayant pour une boutique en ligne ou une landing page de lunettes de soleil.

Projet personnel / prototype de démonstration.
